# Tangram Packages

This repository contains a collection of community maintained Tangram packages. To learn more about Tangram, [click here](https://www.tangram.dev).

## Publishing

Run `tg run .#publish` from the repository to publish every package with `tg publish`, which also creates the builds that each package lists in its `builds` metadata. Arguments after `--` are passed to `tg publish`, such as `tg run .#publish -- --dry-run`.
